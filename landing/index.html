Установка

На Linux VPS — одна команда. Остальное в README на GitHub.

curl -fsSL https://raw.githubusercontent.com/danilax9/telegram-cursor-agent/main/install.sh | bash

Скрипт спросит токен бота, ваш Telegram ID и вход в Cursor CLI.

FAQ

Это ChatGPT в Telegram?

Нет. Cursor Agent с вашими проектами и shell на сервере.

Нужен Cursor IDE на ноутбуке?

Нет — CLI на сервере и Telegram достаточно.

Где лежит код проектов?

В projects_root на VPS, под вашим контролем.

Доступ только для своих?

Да: /access и admin_telegram_ids в конфиге.

Исходники, issues, полный README — на GitHub.
